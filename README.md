# Талгат CRM

Локальная CRM-панель для управления компанией по продаже и установке кондиционеров.

## Что работает

- Воронка заказов: **Новый заказ → В установке → Ожидает оплату → Оплата мастеру → Завершён**.
- Перетаскивание карточек мышью на компьютере.
- Смена этапа нажатием на карточку/кнопку на телефоне и планшете.
- Полностью оплаченный клиентом заказ автоматически переходит на этап «Оплата мастеру».
- Заказ нельзя завершить, пока клиент не оплатил всю сумму и мастер не получил оплату.
- Предоплата и каждый следующий платёж сразу учитываются как поступления.
- Автоматический расчёт остатка долга клиента.
- Вся сумма продажи учитывается как выручка компании.
- Доля менеджера задаётся фиксированной суммой в товаре и при необходимости меняется в заказе.
- Учёт оплаты мастеру, выплаты менеджеру и дополнительных расходов.
- Каталог товаров с фотографиями, названием, описанием, себестоимостью, ценой продажи, долей менеджера и складским остатком.
- Автоматическое списание товара со склада при создании заказа и возврат при удалении заказа.
- Добавление, редактирование и удаление мастеров, менеджеров, товаров, заказов, рекламных расходов и соревнований.
- В карточках мастеров и менеджеров используются только нужные рабочие данные — без поля электронной почты.
- Раздел рекламы для ежедневного учёта расходов на таргет: дата, количество рекламных номеров/аккаунтов, расход на один номер и общая сумма.
- Автоматические итоги рекламы за сегодня, 10 дней, текущий месяц и год.
- Финансовая сводка за 10 дней, месяц, год и всё время.
- Соревнования для мастеров, менеджеров или всей команды.
- Автоматический рейтинг сотрудников по выбранному критерию.
- Выдача бонуса победителю с отражением расхода в финансах.
- Настройки компании: изменение названия до 15 символов и загрузка собственного логотипа.
- Экспорт и импорт полной резервной копии в JSON.
- Адаптивный интерфейс для компьютера, планшета и телефона.
- Все суммы отображаются в сомах.

## Запуск

### Самый простой способ в Windows

Откройте файл `ОТКРЫТЬ_CRM.bat`.

Также CRM можно запустить двойным нажатием на `index.html`.

### Через локальный сервер

Откройте `ЗАПУСК_ЧЕРЕЗ_СЕРВЕР.bat` или выполните:

```bash
python -m http.server 8080
```

После этого откройте в браузере `http://localhost:8080`.

## Хранение данных

Данные сохраняются в `localStorage` браузера на текущем устройстве. Проект запускается без демо-данных и подходит как рабочая локальная версия для одного компьютера.

Для одновременной работы нескольких сотрудников понадобятся:

- сервер и база данных;
- авторизация и роли доступа;
- серверное резервное копирование;
- журнал действий пользователей;
- HTTPS и защита API;
- интеграции с WhatsApp, телефонией или банком при необходимости.

## Логика заказов и финансов

- Любая оплата клиента, включая предоплату, сразу увеличивает фактические поступления.
- Полная сумма продажи является выручкой заказа.
- Доля менеджера — отдельное обязательство компании перед продавцом, а не сумма сверх выручки.
- После полной оплаты клиента заказ переходит на этап «Оплата мастеру».
- Завершение доступно только после отметки об оплате мастеру. Когда стоимость работы мастера равна нулю, дополнительная выплата не требуется.
- Расход мастера, менеджера, таргета, бонуса или дополнительный расход попадает в финансовый отчёт после его фактического проведения.
- Плановая прибыль заказа рассчитывается так:

```text
Сумма продажи
− себестоимость товара
− доля менеджера
− стоимость работы мастера
− дополнительные расходы
```

- Кассовый результат рассчитывается только по фактически полученным и выплаченным деньгам.

## Логика рекламы

При добавлении расхода указываются:

- дата;
- количество рекламных номеров или аккаунтов;
- сумма на один номер в сомах;
- примечание.

Общий расход считается автоматически:

```text
Количество номеров × расход на один номер
```

Например, 4 номера × 500 сом = 2 000 сом расхода на таргет за день.

## Проверка проекта

```bash
node tests/core.test.js
python tests/static_check.py
```

Тесты проверяют новую пятиэтапную воронку, фиксированную долю менеджера, платежи клиента и мастера, рекламные расходы, финансовые периоды, склад и основные ограничения системы.
